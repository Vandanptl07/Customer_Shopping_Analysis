Customer Shopping Behavior Analysis

Project Overview
This project analyzes customer shopping behavior data to uncover purchasing patterns, customer preferences, and business insights. Using Python, SQL, and Power BI, the dataset was cleaned, explored, and visualized to support data-driven decision-making.

Objectives
- Analyze customer demographics and purchasing behavior.
- Identify trends in product categories and customer spending.
- Explore the impact of discounts, subscriptions, and payment methods on purchases.
- Create interactive dashboards for business insights.

Dataset
The dataset contains customer shopping records, including:
- Customer demographics (Age, Gender, Location)
- Product categories
- Purchase amounts
- Payment methods
- Subscription status
- Discount usage
- Purchase frequency

Tools & Technologies
-Python(Pandas, NumPy, Matplotlib, Seaborn)
-SQL
-Power BI
-Jupyter Notebook


Project Workflow
1. Data Cleaning
- Removed inconsistencies and missing values.
- Standardized data formats.
- Prepared the dataset for analysis.

2. Exploratory Data Analysis (EDA)
- Analyzed customer demographics.
- Examined spending behavior and purchase trends.
- Identified popular product categories.
- Evaluated customer purchasing frequency.

3. SQL Analysis
- Queried customer and transaction data.
- Generated business-focused insights.
- Performed aggregations and trend analysis.

4. Dashboard Development
Built an interactive Power BI dashboard featuring:
  - Customer demographics overview
  - Product category performance
  - Purchase trend analysis
  - Payment method distribution
  - Key business KPIs

Key Insights
- Identified customer segments with higher spending patterns.
- Determined the most popular product categories.
- Analyzed the effect of discounts on purchasing behavior.
- Discovered trends related to payment preferences and subscription status.
  
Files Included
